## Neovarch Agent 1.4.8

Rilis ini membawa **codemode** (satu program memanggil banyak alat dalam satu panggilan model), **Kantor ala Paperclip** yang pegawainya benar-benar bekerja, **`neovarch update`** dan cek pembaruan dari GitHub Releases, **Pamerkan** dengan radar dari pemakaian nyata, **Vault Obsidian asli** yang tersambung ke proyek agen, **Tempest v2** dengan `web_search` tanpa konfigurasi, alat agen yang lebih pintar, Mode Desain, dan chat Android yang lebih rapi. Berisi PR #37–#57.

### Penting saat memperbarui

- **Perbarui aplikasi desktop dan aplikasi HP bersamaan.** Feed Kantor, kendali heartbeat, grafik token, dan Pamerkan di HP butuh core 1.4.8.
- **Heartbeat Kantor kini aktif secara bawaan** begitu perusahaan ada. Perusahaan lama yang belum pernah diubah dinyalakan sekali saat upgrade; pilihan Anda setelahnya tetap dihormati. Sakelar **Jeda heartbeat** ada di desktop dan HP.
- **Pembaruan berikutnya tanpa unduh manual:** mulai versi ini desktop memeriksa GitHub Releases, dan `neovarch update` / tombol **Perbarui** di Pengaturan ▸ Tentang memasang versi baru.

### Codemode (PR #54)

- **Alat `codemode`** (Tempest, `agent.tempest_codemode`, bawaan menyala): model menulis **satu program Python** yang memanggil alat lain lewat `tools.<nama>(...)`, `tools.call(...)`, dan `tools.parallel([...])`, lalu hanya mencetak yang penting. Satu panggilan model menggantikan banyak.
- **Aman:** program jalan di proses Python terpisah (`python -I`) dengan timeout dan batas CPU/memori; tanpa jaringan dan tanpa menjalankan proses secara bawaan. Setiap panggilan alat di dalam program lewat gerbang yang sama dengan panggilan langsung: persetujuan perintah berbahaya, mode `/rencana`, cek sintaks, checkpoint, hooks, dan ledger.
- **Hasil uji replay** (10 tugas lokal, `core/bench/codemode_bench.py`): panggilan model **−60%** dibanding satu alat per panggilan dan −39% dibanding baca paralel yang sudah ada; prompt token −60% / −41%. Belum diukur dengan model sungguhan.

### Kantor ala Paperclip (PR #55)

- **Pegawai tidak lagi diam:** heartbeat (autorun) aktif begitu perusahaan ada.
- **Strategi CEO:** tiap tujuan aktif tanpa pekerjaan otomatis mendapat tiket **Susun strategi** untuk CEO, yang mengajukan rencana + tiket untuk timnya; dewan bisa **menyetujui, minta revisi, atau menolak**.
- **Rekrut dan anggaran:** agen bisa minta rekrut, selalu lewat persetujuan. Biaya dicatat per panggilan model; batas anggaran menghentikan heartbeat yang sedang jalan dan mengajukan satu persetujuan anggaran.
- **Feed live** (desktop **Aktivitas live**, HP **Feed**), **thread tiket** (komentar + jejak audit + run heartbeat), dan bagan organisasi sebagai kotak bersambung.
- **Kendali dari HP:** lihat feed, setujui/tolak/minta revisi, tugaskan tiket, jeda/lanjutkan heartbeat.

### Pembaruan Windows/Linux (PR #38, #56)

- **`neovarch update`** dan tombol **Perbarui** di Pengaturan ▸ Tentang. Instalasi git: `git fetch` + fast-forward saja, dependensi dipasang ulang, dan **rollback otomatis** bila gagal atau dibatalkan (`neovarch update --rollback` kembali ke commit sebelumnya). Perubahan lokal yang belum di-commit atau branch yang diverged ditolak dengan pesan jelas.
- **Bukan instalasi git:** installer resmi dijalankan untuk rilis terbaru; AppImage/.deb membuka halaman rilis.
- **Cek pembaruan dari GitHub Releases** (menu Check for Updates… dan Pengaturan ▸ Tentang): Linux (install.sh) **Update sekarang** lalu mulai ulang, Windows mengunduh dan menjalankan `neovarch-agent-windows-x64-setup.exe`. Cek senyap saat start paling sering sekali per 24 jam.
- Setelah pembaruan, ekstra opsional (mis. Obsidian) diperiksa dan dipasang bila perlu.

### Pamerkan (PR #57)

- **Radar/spider chart dari pemakaian nyata** dengan 6 sumbu: coding, riset, PPT, browser, otomasi, token (`GET /api/pamerkan`).
- Grafik **bar, donut, dan tren** harian/mingguan; **widget bisa disembunyikan** (pilihan tersimpan); lebih banyak tema, tata letak, dan latar; ekspor gambar.
- Data hanya dari file lokal PC, tidak ada yang dikirim keluar. Tanpa data, kartu menampilkan keadaan kosong, bukan angka palsu.

### Vault jadi vault Obsidian asli (PR #52, #53)

- Vault Neovarch kini **format Obsidian asli**: Markdown + frontmatter, `[[wikilink]]`, `#tag`, dan folder `.obsidian/`, jadi langsung bisa dibuka di aplikasi Obsidian.
- **Tersambung ke proyek agen:** hub `Neovarch.md` → catatan proyek → catatan sesi → berkas yang diubah agen. Graf bawaan ala Obsidian dengan garis tautan.
- **Migrasi aman:** cadangan zip dulu, catatan lama tidak diubah, memori agen disalin. `neovarch vault init` / `neovarch vault sync`.
- **Ekstra opsional dipasang otomatis** (dengan persetujuan) saat instalasi, pembaruan, atau sesuai permintaan, hanya dari sumber resmi dan tidak dibundel: Windows senyap per pengguna, Linux AppImage + handler `obsidian://`, Android membuka Play Store. Graf bawaan tetap jalan tanpa Obsidian.

### Tempest v2 (PR #39)

- **`web_search` tanpa konfigurasi** dan tanpa API key: rantai fallback DuckDuckGo → DDG lite → Bing → browser headless → Wikipedia, cache 10 menit. **`web_fetch`** dengan ekstraksi ala readability dan fallback browser headless.
- Hasil alat baca-saja langsung masuk konteks (tidak di-offload), alat baca-saja **jalan paralel**, penalaran Ultra adaptif, dan **aturan grounding + cek angka** terhadap sumber yang benar-benar dibaca.
- Uji langsung (mimo-v2.6-flash-free, Ultra): SimpleQA 5 soal 4/5 → **5/5**, waktu rata-rata 38,8 → **14,5 dtk**.

### Alat agen (PR #40, #47, #48)

- **`edit_file` toleran** (spasi, CRLF, kutip miring, indentasi) dengan multi-edit semua-atau-tidak dan pesan galat yang menunjuk region paling mirip; alat **`grep`** dan **`glob`**; **`shell`** menyimpan output saat timeout dan bisa jalan di latar (`shell_job`).
- **`apply_patch`** multi-berkas (format V4A, semua-atau-tidak, dicek sintaks di Tempest), **`repo_map`**, **`task`** (maks. 4 sub-agen baca-saja paralel), **hooks** pengguna di `~/.neovarch/hooks.json` (hooks di dalam repo tidak pernah dijalankan), mode **`/rencana`**, serta `CLAUDE.md` dan `~/.neovarch/AGENTS.md` global.
- **Mode Desain (`/desain`)** mengikuti alur OpenDesign: design system di `.neovarch/design/` (DESIGN.md + tokens) yang otomatis dipakai agen saat coding UI, artifact HTML + pratinjau, kritik diri, cek token, dan skill desain bawaan berlisensi permisif.

### Chat & HP

- **Satu gelembung per giliran agen (#41):** satu header, timeline live di dalam (penalaran, alat, narasi), jawaban akhir di bawah, satu tombol Salin; langkah lama dilipat di balik **+N langkah**.
- **Header chat (#42):** status selebar penuh (tidak lagi "langkah 9/3…") dan mode fokus saat scroll.
- **Diagram live (#43):** blok mermaid/svg jadi kartu **Pratinjau | Kode**, render offline, layar penuh dengan pinch-zoom.
- **Pemakaian token (#44, #51):** satu arti untuk semua penyedia (cache tidak lagi terhitung dua kali), usage stream digabung, "sejak <tanggal>", dan tampilan grafik: Hari ini | Sesi | Semua, tren 14 hari, per model.
- **Mik (#45):** strip status dikte, alur izin + Speech Services yang jelas, watchdog; transkrip masuk ke kolom dan tidak terkirim otomatis.
- **Mode ringan (#46)** selalu bisa dimatikan (switch paling atas Tampilan + chip Matikan). **Composer (#50):** nama model tidak lagi tampil dua kali.
- **Profil (#49):** token GitHub yang ditolak tidak lagi memunculkan "pasangkan ulang"; HP menampilkan **Masuk GitHub lagi di PC**.
